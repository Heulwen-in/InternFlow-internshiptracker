# Internship Tracker

A full-stack job and internship application management system for students and graduates.

## Tech Stack

- React
- Node.js
- Express
- PostgreSQL
- Prisma
- JWT Authentication
- Docker
- GitHub Actions

## Main Features

- User authentication
- Application tracking
- Company management
- Status pipeline
- Notes
- Tasks and reminders
- Dashboard analytics
